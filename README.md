# GitHub community health defaults / 共通Issue入口

ZeroRoomLab / `saitoomituru` repositories share these default issue forms **only when a repository does not have its own templates**.

**日本語推奨。ただし英語・その他の言語も歓迎します。** Japan-first review capacity is a current maintainer preference, not a contributor eligibility test. Localization can expand when bilingual/multilingual maintainers join.

- Bug / observation / counterexample: `.github/ISSUE_TEMPLATE/01-report.yml`
- Proposal / design / translation: `.github/ISSUE_TEMPLATE/02-proposal.yml`
- Blank issue is enabled for other cases.

Read each repository's `AGENTS.md` and CONTRIBUTING. Do not attach personal data, secrets, or restricted third-party information. See the [cross-repository contribution guide](https://github.com/saitoomituru/ZeroRoomLab-manifest/blob/main/docs/operations/issue-contribution-guidelines.ja.md).

**An issue is input to review, not permission to run an agent, execute code, change authority, or merge a PR.**
